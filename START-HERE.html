브라우저에서 보기

웹앱이라 더블클릭으로 여는 파일은 없습니다. 개발 서버를 켜야 합니다.

  1. 파일 탐색기에서 C:\Users\leeta\Desktop\Branreach\web 폴더로 이동
  2. 주소창에 cmd 입력 후 Enter (그 폴더에서 터미널 열림)
  3. 아래 명령 실행 (첫 실행만 npm install 필요)
npm install npm run dev

그다음 브라우저에서 열기 → http://localhost:3000

이미 서버가 떠 있으면 npm run dev 는 "port 3000 in use" 로 뜹니다. 그냥 위 주소로 접속하면 됩니다.

배포 체크리스트 (Phase 6)

  1. Vercel 에서 GitHub 레포 branreach/branreach import
  2. Root Directory 를 web 로 설정 (앱이 web/ 하위에 있음)
  3. Vercel 환경변수 입력: NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_ANON_KEY, NEXT_PUBLIC_SITE_URL (배포 도메인)
  4. Supabase → Authentication → URL Configuration: Site URL + Redirect URL 에 배포 도메인 추가
  5. Supabase → Authentication → Email: "Confirm email" 다시 ON
  6. 배포 후 production 에서 3대 흐름 재확인 (인플루언서 / 브랜드 / 운영자 매칭)

service_role 키는 필요 없습니다 — Admin 은 RLS is_admin() 로 동작합니다.
